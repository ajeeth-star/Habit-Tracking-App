# HabitApp

A private iPhone app for building habits. The user creates tasks (gym, skincare, guitar), each with scheduled weekdays, one daily time window, and a weekly allowance of skips. A task is completed only by taking a photo with the in-app camera during its window. Streaks (shown as weeks + days) reward showing up; skips keep a streak alive without growing it. v1 is single-user and fully on-device; shared "folders" with friends are a possible future, so don't design in ways that block them — but don't build them. The full product reference is `docs/context.md`.

## Tech decisions

- Native iPhone app: **Swift + SwiftUI**, minimum **iOS 17**, **iPhone only, portrait only**.
- All data stays on the device. Persistence will be **SwiftData** (not added yet). No backend, server, accounts, or network calls.
- Project is generated by **XcodeGen**: `project.yml` is the source of truth. `HabitApp.xcodeproj` is generated and git-ignored — never edit it by hand.
- Tests use **Swift Testing** (`import Testing`, `@Test`, `#expect`).
- Editor is **VS Code** (Apple's Swift extension + SweetPad). Xcode stays installed for its build tools and simulator.
- No web tooling (Node.js, Python, etc.). No third-party Swift packages without asking.
- Bundle ID: `com.ajeethsrinivasan.habitapp`. Camera permission text lives in `project.yml` (→ `App/Info.plist`).

## Design rules

- Views never hard-code a color, font, spacing value, corner radius, or size: use `Color.app.*`, `Font.app.*`, `Spacing.*`, `Sizes.*`, `Radius.*`.
- All user-facing text lives in `DesignSystem/Strings.swift`; text built from data goes through `Formatters`.
- To check screens: in a DEBUG build, tap the paintbrush (top left of Home) to open the Design Gallery. Every screen and state is listed there, with light/dark and streak-format switches.
- To open one gallery entry directly (e.g. for screenshots): launch with `-galleryEntry <id>`, e.g. `xcrun simctl launch booted com.ajeethsrinivasan.habitapp -galleryEntry home.all`. Ids are in `Views/Gallery/DesignGalleryView.swift`.

## Commands

```sh
# Regenerate the Xcode project (after editing project.yml or adding/removing files)
xcodegen generate

# Build for the simulator
xcodebuild -project HabitApp.xcodeproj -scheme HabitApp \
  -destination 'platform=iOS Simulator,name=iPhone 16' \
  -derivedDataPath build/DerivedData build

# Run the unit tests
xcodebuild -project HabitApp.xcodeproj -scheme HabitApp \
  -destination 'platform=iOS Simulator,name=iPhone 16' \
  -derivedDataPath build/DerivedData test

# Install and launch in the simulator (after building)
xcrun simctl boot "iPhone 16"; open -a Simulator
xcrun simctl install booted build/DerivedData/Build/Products/Debug-iphonesimulator/HabitApp.app
xcrun simctl launch booted com.ajeethsrinivasan.habitapp
```

## Working rules

- **Plain-language explanations.** The owner is new to iOS. If a technical term is needed, explain it in one line.
- **One feature per phase; don't build ahead.** Phases are listed at the end of `docs/context.md`.
- **Ask before adding any dependency or third-party package.**
- **No network code** of any kind.
- **`docs/context.md` is the product reference.** When a product decision comes up that it doesn't answer (see its "Still open" section), stop and ask the owner instead of guessing.
